# 飞鸽登录/注册 · 分栏海报门页设计

日期：2026-10-30  
状态：待实现

## 目标

将登录、注册门页改为「分栏海报」布局，并升级品牌图标为更精致的青绿鸽衔信形象，使首屏品牌感更强、表单区更清晰。

## 范围

- 改动：`login.html`、`register.html`、门页相关 CSS（`app.css` 中 `.gate` / `.card` 等）、`favicon.svg` / `favicon.png`，以及全站引用该图标的品牌标。
- 不改：聊天主界面结构、管理页功能、鉴权接口与表单字段语义。

## 布局

### 桌面（≥900px）

- 全屏左右分栏，约 `1.05fr` / `0.95fr`（左略宽）。
- **左侧品牌区（全幅视觉平面）**
  - 青绿氛围：径向/线性渐变 + 轻纹理；信标主题下为深底 + 青绿网格/光晕。
  - 主视觉：放大后的品牌图标（非小 favicon 贴片）。
  - 品牌名「飞鸽」为 hero 级字号；一句短支持文案（登录：「局域网里的信使」；注册：「给自己取个好认的名字」）。
  - 左侧不放表单、不放统计/次要营销块。
- **右侧表单区**
  - 白底（信标为深卡片底）垂直居中内容柱，最大宽约 380px。
  - 顺序：小品牌锁（可选）→ 标题 → 说明/错误 → 用户名 → 密码 → 主按钮 → 切换链接。
  - 输入框与按钮圆角、间距与现有 celadon 语言一致但更整齐。

### 窄屏（&lt;900px）

- 改为上下：上品牌条（图标 + 飞鸽 + 短句，高度克制），下表单；保证一屏内可完成登录，不必横向滚动。

## 图标

- 新 SVG：青绿圆角底、白鸽衔信封，浮雕/柔和光感，去掉旧蓝底稿残留。
- 导出/生成 `favicon.png`（圆角）供 `<link rel="icon">` 与 `<img class="brand-mark">`。
- 登录左侧用更大尺寸同一素材（可 CSS 放大 PNG，或内联 SVG）。

## 主题

| 主题 | 左侧 | 右侧 |
|------|------|------|
| 信笺 (classic) | 青绿雾面渐变 + 纸感 | 白底表单 |
| 信标 (signal) | 深底 + 青绿网格/光晕 | 深卡片表单，描边同现有 signal |

主题仍由现有 cookie / `theme.js` 驱动，门页继续读 `data-theme`。

## 文案（可微调，实现时落死）

- 登录标题：登录；主按钮：进入；切换：还没有账号？注册
- 注册标题：注册；主按钮：注册；切换：已有账号？登录
- 左侧短句见上；保留原有校验错误展示位置（表单上方）。

## 验收

1. `/login`、`/register` 桌面为左右分栏，品牌在左、表单在右。
2. 窄屏为上下分栏且表单可用。
3. 新图标出现在门页主视觉、favicon、聊天侧栏品牌标。
4. 切换信笺/信标后门页观感正确；登录/注册功能与 CSRF 行为不变。
5. 硬刷新后无旧蓝图标缓存问题（路径仍为 `/favicon.png`，内容已换）。

## 非目标

- 不引入第三方登录、记住我、验证码。
- 不改管理端账号禁用等未完成需求。
